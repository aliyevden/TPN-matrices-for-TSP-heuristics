### to accompany the Tree-Penalized Distance Matrices with Noise: An Application to TSP Heuristics by Aliyev et.al. ###
1) experiments_R_code_TPN_paper.txt file contains the R code for the main experiments: runs given heuristics on D, tp, and tpn matrices multiple times, computing tour lengths.
2) auxiliary_R_functions_TPN_paper.txt fil contains the auxiliary custom R functions used in 1).
3) tpn_all_violin_plots.pdf file contains the violin plots of the distribution of tour lengths for all 36 methods on 70 TSP instances.
4) combined_summary_tpn.csv file contains full tables of performance metrics for all 36 methods on 70 TSP instances.
